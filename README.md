# Minogami（美濃紙）

Obsidian で**縦書きのまま編集できる**ビュー。プレーンテキスト専用です。

- 書いている最中がずっと縦組。編集とプレビューが別画面になりません
- **Markdown の装飾は描きません。** 記号はそのまま見えます
- 小説専用ではありません。縦書きで書きたいもの全般のための面です
- ファイルの実体は普通の `.md` のまま。同じノートを横書きで開き直せます

**実験段階です。** 大事なノートはバックアップを取ってからお使いください。

## 入れかた（BRAT）

1. コミュニティプラグインから **BRAT** を入れる
2. BRAT の «Add beta plugin» に `msonrm/obsidian-minogami` を指定
3. 設定 → コミュニティプラグイン で **Minogami** を有効化

## 使いかた

ノートを開いて、**リボンの ¶ アイコン**か、コマンド «縦書きで開く / 横書きに戻す»。
もう一度押すと元の Markdown ビューに戻ります。

| キー | 動き |
|---|---|
| ↑ ↓ | 字送り（行に沿って進む） |
| ← → | 行移動（← が次の行） |
| Home / End | 行頭 / 行末（Ctrl 併用で文頭 / 文末） |
| PageUp / PageDown | ページ送り（縦組なので横に進みます） |
| Ctrl+Z / Ctrl+Shift+Z | 元に戻す / やり直す |

設定で **1 行の字数**を指定できます（0 でペインの高さいっぱい）。画面に入りきらない
ときは自動で折り返し、実際の字数を下に表示します。

下段には `いま / 全体` の形で字数・行数と、400 字詰め原稿用紙の換算枚数が出ます。
枚数は**行単位で数える**ので、短い行も 1 行を消費します（文字数を 400 で割った値とは
一致しません）。

## 日本語入力について

そのままでも OS の日本語入力で書けます。

**[hechima](https://github.com/msonrm/obsidian-hechima)**（Obsidian の中で動く日本語入力）
を併用すると、未確定文字も変換候補も**縦組で**出ます。薙刀式・月配列・NICOLA などの
配列もそのまま使えます。hechima v0.13.0 以降が必要です。

## できないこと

Obsidian の標準エディタ（CodeMirror）を使わず、縦書きのために表示と入力を自前で
持っているため、このビューでは次が効きません。

- Markdown の装飾表示、リンク補完、検索ハイライト、アウトライン、Vim モード
- エディタ系のコマンド全般

「原稿を書く面」と割り切る前提の作りです。横書きに戻せばすべて使えます。
